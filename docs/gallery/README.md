# Stash Radar Plugin gallery

In-game shots are real screenshots taken automatically in CI (Superflat, noon, clear, 1920x1080, Paper + LogicLib Plugin). Title card and explainers are drawn graphics around real screenshots.

- **Stash Radar Plugin** (plugin-00-title.png): /find your stuff on Paper servers. Players need no mod.
- **How it works** (plugin-12-how-it-works.png): Type /find and an item, the server checks, and the containers that hold it light up.
- **Find it in your storage** (plugin-01-storage-wall.png): /find diamond outlines the 4 containers on this wall that hold diamonds.
- **Outlines up close** (plugin-02-closeup.png): Only the containers with the item get an outline, and only you see it.
- **Looks inside shulker box items** (plugin-13-inside-shulker.png): A chest lights up when the emeralds are inside a shulker box stored in it.
- **Shulker box item found** (plugin-03-inside-shulker-item.png): Real shot: /find emerald finds the chest that holds a shulker box full of emeralds.
- **Pick how far it looks** (plugin-14-range.png): The same search with range 8 finds 2 containers, with range 24 it finds all 5.
- **Search the whole yard** (plugin-05-yard-range-24.png): /find iron_ingot 24 outlines every container with iron around the field.
- **The answer in chat** (plugin-08-chat-result.png): How many you have, in how many containers, and where the nearest one is.
- **Tab-complete** (plugin-09-tab-complete.png): Type /find and press Tab to see matching items.
- **Permissions and cooldown** (plugin-15-permissions.png): Everyone can search; operators skip the cooldown and can reload the config.
- **Nothing nearby** (plugin-10-chat-nothing.png): A clear answer when no container in range holds the item.
